# Kice Island Paddle Windows

A tool that pulls live NOAA tide data to recommend the best times to paddle/kayak across to Kice Island near Marco Island, FL — without fighting the current.

## What it does
Current runs weakest near slack water (the hour on either side of a high or low tide) and strongest at mid-tide. This tool calculates and displays the best 2-hour daylight windows to cross, centered on slack water. High-tide windows are marked as best when they overlap, since they also provide more water clearance over the sandbars near Kice.

## Data source
Live tide predictions from NOAA Station 8724967 (Caxambas Pass).

## Why I built it
A personal project to learn to work with real-time API data and build something genuinely useful for local paddlers — and a first step in my move toward AI/ML engineering after a background in journalism and communications.
